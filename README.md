# 🌐 NEXORA Browser

### Browse Beyond Limits.

**NEXORA** is a modern desktop web browser built with Electron. It is designed to provide a simple, convenient, and customizable browsing experience with useful built-in tools and features.

## ✨ Features

NEXORA combines everyday browsing with useful built-in tools.

### 🌍 Web Browsing
- Browse websites using HTTP and HTTPS.
- Navigate between pages.
- Go back and forward through browsing history.
- Reload pages.
- Enter website addresses directly.
- Open multiple tabs.
- Switch between tabs.
- Create and close tabs.
- Automatic page title updates.
- Open links in new tabs.

### 🔍 Brave Search Integration
- Search the web using Brave Search.
- Search directly from the browser homepage.
- Get search results without manually opening a search engine.
- Convenient search interface.

### 🕶️ Private Browsing
- Open private browsing tabs.
- Keep private browsing separate from regular browsing.
- Private tab activity is excluded from the browser's saved browsing history.

### ⭐ Bookmarks
- Save favorite websites.
- View saved bookmarks.
- Open bookmarked websites.
- Remove bookmarks.
- Store bookmarks locally.

### 🕘 Browsing History
- Automatically record visited websites.
- View previously visited pages.
- Display page titles, URLs, and visit dates.
- Open websites directly from history.
- Clear browsing history.

### 🌤️ Weather
- Built-in weather section.
- Location detection support.
- Convenient access to weather information.

### 📝 Notes
- Built-in notes section.
- Write and manage notes while browsing.

### 🌐 Translator
- Built-in translator section.
- Access translation functionality directly from the browser menu.

### ⚡ Internet Speed Test
- Built-in shortcut to an internet speed testing service.
- Quickly check your internet connection.

### ⚙️ Settings
- Browser settings panel.
- Language selection.
- Update checking.
- Update status notifications.

### 🌍 Language Support
NEXORA supports Russian and is currently developing English language support.

- Russian interface.
- English interface in selected sections.
- Language selection.
- Language preference saved between sessions.
- English translation progress: **50% completed**.

English localization is still a work in progress. Some interface elements may remain in Russian.

### 🔄 Automatic Updates
- Built-in update checking.
- Update availability notifications.
- Download progress notifications.
- Update download completion notifications.
- Powered by `electron-updater`.
- GitHub Releases integration.

### 🧭 Popup Menu
The NEXORA popup menu provides quick access to:
- Bookmarks.
- Browsing history.
- Weather.
- Notes.
- Translator.
- Internet speed test.

The menu can be closed by clicking outside its window.

### 🛠️ Developer Tools
- Built-in Chromium Developer Tools.
- Open and close Developer Tools using `Ctrl + Shift + I`.
- Useful for debugging and development.

## 🚀 Development

To run NEXORA locally:

1. Install [Node.js](https://nodejs.org/).
2. Clone the repository.
3. Open the project directory in a terminal.
4. Install dependencies:

```bash
npm install
```

5. Start the application:

```bash
npm start
```

### Build

To build the Windows application:

```bash
npm run build
```

The generated installation files will be available in the `dist` directory.
